
# Project Instructions

## Project Overview

This project is a reusable website template for building client websites.

The template uses:
* Next.js with App Router
* React
* React Bootstrap and Bootstrap 5
* CSS Modules and global CSS
* Animate on Scroll (AOS)

The template is primarily intended for static business websites deployed to Cloudflare Pages.

Each client project will be customised with different branding, content, images, pages and functionality.

## General Rules

* Follow the existing project structure and coding conventions.
* Keep code clean, readable, maintainable and reusable.
* Prefer simple solutions over unnecessary complexity.
* Do not introduce new dependencies without explaining why they are needed.
* Do not change unrelated code or functionality.
* Do not remove existing features without permission.
* Do not generate images unless explicitly requested.
* Ask for clarification when requirements are unclear.

## Next.js and React

* Use the Next.js App Router.
* Prefer Server Components where possible.
* Use Client Components only when necessary.
* Follow best practices for the installed Next.js and React versions.
* Keep the project compatible with static export.
* Do not introduce server dependent functionality without approval.
* Use reusable components where appropriate.

## Styling

* Use React Bootstrap and Bootstrap for layouts and components.
* Use CSS Modules for component and page specific styling.
* Use global CSS for shared styles and theme variables.
* Maintain responsive layouts across mobile, tablet and desktop.
* Keep styling easy to customise for different clients.
* Respect accessibility and reduced motion preferences.

## Security

* Follow current Next.js and React security best practices.
* Never expose API keys, credentials or sensitive information.
* Do not commit secrets or environment files.
* Review third party dependencies for security risks.
* Avoid unsafe HTML rendering and unnecessary external scripts.

## Performance and SEO

* Prioritise good Core Web Vitals and Lighthouse scores.
* Optimise images, fonts and scripts appropriately.
* Use semantic HTML and accessible components.
* Include appropriate metadata and SEO configuration.
* Keep SEO settings easy to customise for each client.

## Working With Codex

* Before making changes, inspect the relevant files.
* Explain proposed changes before implementing significant modifications.
* Make only the changes requested.
* Keep modifications focused and avoid unnecessary refactoring.
* Preserve existing functionality unless instructed otherwise.
* Run appropriate checks after making changes.
* Report any errors or issues discovered.
* Do not deploy, install packages or modify dependencies without approval.

## Client Customisation

* Treat this project as a reusable template rather than a finished website.
* Avoid hardcoding client specific information into shared components.
* Keep branding, metadata and business details easy to update.
* Do not add features that every client may not need.
* Prioritise simplicity, reusability and ease of maintenance.
