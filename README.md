# Next.js Static Site Boilerplate

A reusable **Next.js static site template** for client projects.  

## Features

- Dark theme with **Roboto font**  
- **Bootstrap 5** styling & responsive layout  
- **AOS scroll animations** ready  
- Global layout with **Navbar** + **Footer**  
- Example **Home** and **Contact** pages  
- Metadata / SEO helper (`generateMetadata`)  
- Fully responsive, mobile-ready  

---

## 🚀 Getting Started

### 1. Clone the template

    git clone https://github.com/yourusername/nextjs-static-template.git new-client-site
    cd new-client-site

### 2. Install dependencies

    npm install

### 3. Run the development server

    npm run dev
    Open http://localhost:3000 to view the site.

### 4. Build for production

    npm run build → generates .next folder
    npm run export → generates static out/ folder ready for Cloudflare Pages or any static host
